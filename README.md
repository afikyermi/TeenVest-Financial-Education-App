# TeenVest - Financial Education Web App

TeenVest is an interactive web project designed to help teens learn basic financial concepts in a simple and engaging way.

## Project Overview
This project was built as part of my academic work and focuses on creating an accessible financial education experience for young users.  
A significant part of the project involved designing and implementing the application logic, financial calculations, and decision-making flows that drive the interactive learning experience.

## Built With
- HTML
- CSS
- JavaScript

## Features
- Interactive user interface
- Educational financial content for teens
- Responsive front-end structure
- Dynamic behavior using JavaScript
- Logic-based financial calculations and decision flow implementation
